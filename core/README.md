# core/

منطق التطبيق الخالص (بدون واجهة) موجود داخل `app/lib/core/`:

- `models.dart`: القالب الأسبوعي، أيام الأسبوع، حالات الأسابيع، الأيام غير الدراسية، أوراق الدعم، وبيانات التطبيق كلها.
- `scheduler.dart`: بناء الجدول الفعلي من القالب والمنهج والأيام غير الدراسية. القواعد:
  - الدروس تُسنَد بالترتيب داخل كل مادة، ولا تنتقل إلى مادة أخرى.
  - اليوم غير الدراسي يؤخر درس المادة إلى حصتها التالية.
  - الأسابيع المتوقفة والتقويم تجمّد التقدم.
  - يومان ضائعان في الإدماج تنبّه إلى إعادة جدولة الوحدة من بداية الأسبوع التالي.

الاختبارات في `app/test/scheduler_test.dart`.
