# مكتب المعلم 🌸

تطبيق Flutter لمعلمة السنة الثانية ابتدائي، يجمع المذكرات، والجدول الزمني، ولوحة القيادة الأسبوعية، وأوراق الدعم، في مكان واحد.

## الحالة
- المواصفات مكتوبة في `docs/spec.md`.
- التصميم والألوان في `docs/design.md`.
- الكود في مرحلة الهيكل الأولي.

## الهيكل
```
app/      تطبيق Flutter (الهاتف)
core/     منطق الجدولة والقوالب المشتركة (سيُضاف لاحقاً)
docs/     المواصفات والتصميم
```

## الخصوصية
- كل البيانات محلية على الهاتف، ولا تُرفع إلى أي خادم.
- التلاميذ يُسجَّلون بالاسم واللقب داخل الجهاز فقط، ولا تُشارَك البيانات.
- مفتاح Gemini يُحفظ على الهاتف فقط، ولا يُكتب في الكود أو في المستودع.
- ملفات البيانات والمفاتيح مستبعدة عبر `.gitignore`.
